**Pixel Computer Gruvbox**

This theme is based on [Pixel Computer for iPod Classic](https://themes.rockbox.org/index.php?themeid=3911&target=ipod6g), with the addition of a [gruvbox](https://github.com/morhetz/gruvbox) color scheme, [IBM Plex Mono](https://www.ibm.com/plex/) fonts, and *(hopefully)* clearer documentation.
